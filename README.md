# UVA2
An updated flexible global parametrization of GPDs from elastic and deeply inelastic inclusive scattering data. To use this parameterization, download the grids and interpolate using the method described in the paper: 

Zaki Panjsheeri, Douglas Q. Adams, Adil Khawaja, Saraswati Pandey, Kemal Tezgin, and Simonetta Liuti. “Updated flexible global parametrization of generalized parton distributions from elastic and deep inelastic inclusive scattering data,” Eur. Phys. J. C 86, 1078 (2026).

The columns in the files posted here are organized in order of &zeta;, t, Q^{2}
